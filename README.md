# Maravelle Show Player

Tap-to-play audio player for the Ghaf Woods × Maravelle show iPads, served with GitHub Pages.

- `index.html` – the player
- `show.json` – buttons, layout, background and edit code (written by the player's **Publish** button)
- `media/` – the tracks
- `assets/` – background, logos and app icons
- `sw.js` – keeps a copy on each iPad so it works without Wi-Fi

Edit on a laptop: open the site, press **E** (or triple-tap the top-right corner), enter the code, make changes, then **Publish to all iPads**.
Publishing needs a fine-grained GitHub token with *Contents: Read and write* on this repository, saved once in the player's Settings on that laptop.
